Drop your CeSHHAR MASCOT mHealth project photos/screenshots in this folder
(e.g. screen-1.jpg, screen-2.png), then list the matching paths in the
`gallery` array for the CeSHHAR project in lib/data.ts, like:

  gallery: [
    "/images/projects/ceshhar/screen-1.jpg",
    "/images/projects/ceshhar/screen-2.jpg",
  ],

Delete this README once you've added real images.
