Drop your Codico graphic design pieces (Photoshop/Figma exports, social
media creatives, UI/UX mockups, etc.) into this folder, e.g. design-1.jpg,
design-2.png, then list the matching paths in the "Graphic Design Work at
Codico Software Solutions" project's `gallery` array in lib/data.ts:

  gallery: [
    "/images/projects/codico/design-1.jpg",
    "/images/projects/codico/design-2.jpg",
  ],

Delete this README once you've added real images.
